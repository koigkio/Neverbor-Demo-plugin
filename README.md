# 🪶 Neverbor

**Плагин для Claude Code, который бережёт ваши лимиты.**

Сжимает «шумный» вывод инструментов *до того*, как его прочитает модель, и приучает Claude отвечать коротко.

## ✨ Возможности

- 🗜 **Сжатие вывода Bash и MCP.** Убирает цвета, прогресс-бары и повторы, сокращает длинный JSON и огромные логи.
- 🔁 **Ничего не теряется.** Полный оригинал сохраняется на диск, и Claude может прочитать его, если понадобится.
- ✂️ **Короткие ответы.** В начале сессии Claude получает правила: без вступлений, пересказов и лишних перечитываний.
- 🛡 **Безопасность прежде всего.** Точный вывод (`cat`, `git diff`, `Read`, `Edit`…) не трогается. Если хук упадёт, сессия продолжится как обычно.
- 📊 **Статистика.** Команда `/neverbor` показывает, сколько токенов уже сэкономлено.

## 🚀 Установка

Внутри Claude Code:

```
/plugin marketplace add koigkio/Neverbor-Demo-plugin
/plugin install neverbor@neverbor
```

Или из терминала:

```bash
claude plugin marketplace add koigkio/Neverbor-Demo-plugin && claude plugin install neverbor@neverbor
```

После установки перезапустите сессию. Нужен только Python 3.8+ (в macOS он уже есть).

## 🎛 Команды

| Команда | Что делает |
|---|---|
| `/neverbor` или `/neverbor stats` | статистика экономии |
| `/neverbor on` · `/neverbor off` | включить или выключить сжатие |
| `/neverbor terse on` · `/neverbor terse off` | правила краткости (со следующей сессии) |

<details>
<summary><b>Тонкая настройка</b></summary>

- `# neverbor:off` в конце bash-команды отключает сжатие только для неё.
- `NEVERBOR=0` выключает сжатие через окружение, `NEVERBOR_TERSE=0` отключает правила краткости.
- `NEVERBOR_PASSTHROUGH='rg|kubectl'` добавляет свои команды-исключения.
- `NEVERBOR_DEBUG=1` выводит ошибки хука в stderr.

</details>

## ⚙️ Как это работает

```
Claude вызывает Bash / MCP-инструмент
        │  сырой вывод (логи, find, grep, JSON…)
        ▼
PostToolUse-хук  scripts/post_tool.py
        │  1. убирает ANSI-цвета и перерисовки прогресс-баров (\r)
        │  2. схлопывает повторяющиеся и однотипные строки
        │  3. режет минифицированный JS/base64 (длинные строки без пробелов)
        │  4. JSON: минифицирует, длинные массивы → первые 5 + последние 2 + «ошибочные»
        │  5. >150 строк: голова + хвост + все строки с error/fail/warning/traceback
        │  6. оригинал → ~/.claude/neverbor/cache/…, в конце вывода ссылка на него
        ▼
Claude видит сжатую версию и может прочитать оригинал, если нужно
```

`SessionStart`-хук добавляет в контекст правила краткости, и так уменьшаются ещё и **выходные** токены.

## 🛡 Что не сжимается

- Вывод короче 2 500 символов или с экономией меньше 15%.
- Команды точного просмотра: `cat`, `head`, `tail`, `sed`, `awk`, `jq`, `diff`, `git diff/show/blame` и т. п.
- Инструменты `Read`, `Edit`, `Grep`: при правках Claude нужен точный текст.
- Упавшие команды с ненулевым кодом выхода.

Оригиналы хранятся 3 дня в `~/.claude/neverbor/cache/`.

## 🙏 Идеи позаимствованы у
